# sql-data-analytics-projects

SQL Data Analytics Projects

A collection of SQL scripts demonstrating database management, data cleaning, transformation and analysis.

Projects
1. Comapny Employee database management - structuring employee records, job information and employee-role relationships into related database tables to reduce data duplication and improve data organisation. 
2. Access to Basic Services and Economic Indicators Analysis - analysing access to basic services alongside economic indicators, with a focus on countries in Sub-Saharan Africa using United Nations country-level data.
3. Maji Ndogo Water crisis analysis
